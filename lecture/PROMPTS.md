## ⚠️ Правила безопасности для лекции

- Все атаки — только на **локальный** полигон (127.0.0.1), не на прод.
- НЕ показывай реальные токены/пароли в payload'ах (заменяй на `<TOKEN>`).
- Подчёркивай: знание эксплойтов — для защиты, не для взлома (этика).
- Для учебных токенов — использовать только заведомо одноразовые (HF/локальные).
